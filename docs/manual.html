CHAPTER 01

第一次剪片：從素材到成品

照著六個步驟，完成第一支影片。

先做一支短片，熟悉「加入素材 → 剪輯 → 字幕與配樂 → 儲存 → 匯出」的完整流程。

  1. 用 Edge 開啟 NiVedit。左上角確認版本為 v9.7；若顯示英文，按語言按鈕切成繁體中文。
  2. 加入素材。把影片拖到左側虛線框，或點虛線框選檔案。圖片、音樂與 SRT 也能由這裡加入。
  3. 設定成品尺寸。按「專案設定」，選畫面比例、解析度及影格率。橫式可用 16:9，直式可用 9:16。
  4. 剪掉不需要的部分。選影片方塊，拖曳左右兩端調整起訖；要切成兩段，移動播放頭後按「分割影片」。
  5. 補上字幕與配樂。手動字幕看第 10 章；用「＋ 音軌」加入配樂。播放一次，檢查畫面、字和聲音。
  6. 儲存與匯出。先按左側「儲存」保留可再編輯的專案，再按右上角「匯出影片」。編碼完成後還要按「選擇位置並儲存」。
兩種檔案用途不同。.nvproj 是可繼續編輯的專案；.mp4／.webm 是播放與分享的影片。兩者都留一份。

認識畫面與日夜模式

看懂左右面板、預覽及時間軸。

左側
專案・素材・AI 字幕
中央
影片預覽與播放控制
右側
目前選取項目的屬性
下方時間軸：安排出現的時間、軌道與長度
  • 左側：新建、開啟、儲存專案；匯入素材；產生 AI 字幕或開啟字幕編輯器。
  • 中央：觀看預覽。下方有播放、回開頭、跳結尾、進度滑桿及新增素材按鈕。
  • 右側：先點選一段影片、字幕、標題、疊圖或音軌，這裡才會顯示它的設定。
  • 時間軸：紅線是播放頭；每個方塊表示素材出現的時間與長度。

切換介面

左上角語言按鈕可切中英；旁邊的日夜按鈕可切換「白天模式／夜間模式」。編輯器第一次開啟預設夜間，之後記住你的選擇。這些設定只改介面，不會改變匯出的影片。

時間軸太擠怎麼辦？

拖動播放控制列與時間軸之間的小橫條，可調整時間軸區域高度。滾輪左右捲動，Ctrl＋滾輪縮放時間比例；按「符合視窗」可看完整支影片。

CHAPTER 03

新建、儲存與搬移專案

保留素材與編輯設定，換地方也能接著做。

日常操作

按鈕用途與操作
新建開始一個新專案，依畫面提示命名及選擇存放位置。若目前有工作，先儲存再新建。
儲存把目前剪輯設定與素材存進專案檔。第一次依提示選位置；已有專案時更新目前檔案。
另存另選檔名或位置，保留另一個專案版本，例如「旅遊_初剪」與「旅遊_字幕完成」。
開啟選專案資料夾，再從列表開啟；也可用「匯入專案檔」選一個 .nvproj。

Edge 支援直接讀寫電腦中的 .nvproj 檔案。若瀏覽器要求資料夾編輯權限，允許後才能寫入。不同瀏覽器環境也可能改用瀏覽器內儲存或檔案匯出。

換電腦或從本機搬到網站

  1. 在原本環境儲存 .nvproj。
  2. 把該專案檔複製到目的電腦。
  3. 開啟 NiVedit，按「開啟」→「匯入專案檔」。
本機 HTML 和網站版的瀏覽器專案列表不會自動同步。用 .nvproj 搬移，才能帶著素材和剪輯設定繼續工作。

本機主程式是 NiVedit.html。HTML 是編輯工具，.nvproj 才是你的剪輯內容；修改完字幕或時間軸後，記得按「儲存」。

CHAPTER 04

時間軸與雙影音軌剪輯

分割、移動、留白，以及上下軌的關係。

影片上軌 畫面優先顯示
字幕上軌
影片下軌
字幕下軌

上方影片會蓋住下方影片；上軌裁切外、透明或淡出的地方，能露出下軌。兩軌原聲會一起混音，畫面被遮住不代表聲音也會被關掉。

選取與剪輯

  1. 點選影片方塊，右側出現該片段設定。
  2. 拖方塊中間可改時間位置，也能拖到另一影片軌。右側「放在哪一軌」與「時間軸起點」可精確設定。
  3. 拖影片方塊兩端，調整要使用的片段起訖；也可填右側「裁切」的起點與終點。
  4. 要分割，先選中素材，再把播放頭移到切點，按「分割」或 S。
  5. 選取後按「刪除」可移除項目。需要還原時按「復原」。

片段可以不相連

上下軌都能把影片拖開留白；「接在同軌上一段後面」可快速接齊。兩軌在某段時間都沒有可見影片時，底層是黑色，疊圖、字幕或標題仍按各自時間顯示。

時間軸排列與畫面疊放是兩件事。畫面由下往上依序合成影片、疊圖、字幕、標題；拖動時間軸的大類軌道順序，是整理操作區，不會把配樂變成畫面圖層。

CHAPTER 05

構圖、方向與畫面裁切

調整大小位置，製作矩形或圓形畫面。

選取影片軌上的影片或圖片，在右側「影片構圖」調整水平、垂直、大小、不透明度與旋轉。

設定如何理解
水平／垂直中心座標通常為 0.5；數值越小越靠左／上，越大越靠右／下。
大小1.00 代表目前專案的基準顯示大小，往上增加就是放大。
不透明度1 是完全顯示，0 是完全透明；上軌變透明時會露出下軌。
旋轉構圖與關鍵幀旋轉可設 −360°～360°。正負角度可用來做不同方向的旋轉動畫。
畫面方向影片另有 0°／90°／180°／270° 快捷鍵，用來校正素材方向。

矩形／圓形裁切

  1. 找到「畫面裁切」，把「裁切形狀」改為矩形或圓形。
  2. 矩形調整寬、高與中心；圓形調整直徑與中心。
  3. 再搭配構圖的大小、位置、旋轉與透明度調整。

圓形直徑可以縮到 0，此時整個裁切畫面隱藏。裁切形狀在這一段固定；裁切尺寸與中心可配合關鍵幀變化。

不要混淆兩種「裁切」。影片起點／終點是剪掉時間；「畫面裁切」是決定畫面哪個範圍看得到。

調色與畫面風格

同一段影片的右側還有「畫面風格（這一段）」。可先按「看預覽挑風格」，再微調亮度、對比、飽和、色溫、色調及銳利；展開質感後還有褪色、暗角、顆粒、光暈與復古黃。

「按一下比對原始畫面」方便前後比較；「重設」還原這段的調色。「套用到全部」會把這段的畫面風格複製到其他片段，使用前先確認是否需要全片一致。

CHAPTER 06

起點與終點關鍵幀

讓位置、大小、透明度、旋轉逐漸變化。

目前採用起點 → 終點的兩點式動畫，尚不是可自由新增很多中間點的關鍵幀系統。影片／圖片、PNG／GIF 疊圖及標題都有對應控制項。

  1. 設定起點樣子。在上方構圖區調整位置、大小、透明度及旋轉。
  2. 勾選「關鍵偵開啟/關閉」。下方出現終點控制。介面沿用此字樣；本手冊以「關鍵幀」稱呼。
  3. 設定終點樣子。例如把水平由 0.2 變成 0.8，或讓大小由 0.7 變成 1.0。
  4. 設定動態開始與結束。可填時間、按「現在」取播放頭時間，或拖時間軸方塊中的菱形標記。
  5. 選緩動並播放檢查。動態開始以前保持起點，結束以後保持終點，中間依緩動方式變化。
◆ 藍色底：起點

上方原本的構圖數值。

◆ 紫色底：終點

啟用關鍵幀後的下方數值。

快速對位的兩種作用

  • 「快速對位（終點）」：九宮格只調整終點的位置，起點和其他動畫設定保留。
  • 上方原有的快速對位：未開動畫時直接對位；已有動畫時，會依播放頭當下的位置平移整條起終點路徑。
若只想精確改起點，請用上方「水平／垂直」滑桿。預覽始終依播放頭時間顯示；播放頭在動態開始以前時，修改終點不會讓畫面直接跳成終點。

範例：轉一圈出現

起點旋轉設 0°、終點設 360°，並把不透明度由 0 調到 1。兩端角度雖然看起來同方向，中間仍會旋轉一整圈。若設 −360° → 360°，兩端相差 720°，會轉兩圈。

CHAPTER 07

進入、離開轉場與淡化

分清內扣與外加，每段獨立設定。

  1. 選取一段影片，在右側找「轉場（進入這一段）」與「轉場（離開這一段）」。
  2. 選類型及時長；也可按「看預覽挑轉場」打開動態選單。
  3. 在「這一段的轉場」選內扣或外加。
  4. 播放片段頭尾，確認轉場及聲音。
方式取用畫面對時間的影響
內扣轉場期間使用原片正在播放的畫面。使用片段原有時間，不另外加上頭尾定格。
外加開頭重複第一幀，結尾重複最後一幀。轉場延長片段的時間；定格區間沒有原聲。

兩種方式都允許片段之間留白。外加或延長轉場碰到同軌下一段時，下一段可能被往後推；另一影片軌維持原位置。

這一段淡入淡出

「開場淡入」「結尾淡出」獨立於轉場類型。勾選「聲音一起」，這段原聲會跟畫面一起淡化；取消則只套用這組畫面淡化，其他聲音／轉場效果仍依原設定。

上軌淡出會露出下軌，不一定變成黑畫面。要檢查的是上下軌合成後的預覽結果。

CHAPTER 08

加入圖片、GIF 與疊圖

分辨整段圖片與貼在影片上的動畫貼圖。

入口用途
＋ 圖片把圖片放進影片軌，佔用一段時間。右側可設定停留秒數，也能拉長右端。
＋ 疊圖把圖片或 GIF 放在影片上方，底下影片繼續播放。

加入動畫貼圖

  1. 按「＋ 疊圖」，選擇 GIF。
  2. 選取疊圖方塊，設定「出現／消失」時間。
  3. 調整位置、大小、不透明度、旋轉與淡入淡出。
  4. 需要移動動畫時，啟用關鍵幀並設定起點、終點。

GIF 會從疊圖起點開始播放，循環到疊圖結束，預覽與影片匯出都會保留動畫。若要 GIF 動起來，請使用「＋ 疊圖」；放在影片軌時仍是靜態圖片處理。

多張疊圖互相遮住

選取疊圖後，在右側「圖層順序」使用「往上一層／往下一層」。疊圖會在影片之上、字幕和標題之下；畫面位置與出現時間都要一起檢查。

若已有附贈的 40 款 GIF 素材包，先解壓縮，再從編輯器選取其中的 GIF；素材不是自動出現在內建選單裡。

CHAPTER 09

標題文字與進退場

製作片頭、重點大字與文字動畫。

  1. 移動播放頭到希望標題開始的時間，按「＋ 標題」。
  2. 選取標題方塊，在右側輸入文字，選擇字體、顏色與外觀。
  3. 設定「出現／消失」時間，以及起點的水平、垂直、大小、不透明度、旋轉。
  4. 在「進場動畫」「退場動畫」挑選效果並調整時長。
  5. 要在顯示期間移動、縮放或旋轉，再設定起點／終點關鍵幀。

標題的起點和終點各有大小與旋轉控制，旋轉範圍同為 −360°～360°。進退場動畫會與關鍵幀共同作用，請從前到後播放檢查，不能只看單一時間點。

標題與字幕如何選？一小段醒目的大字、片頭名稱或提示文字可用標題；需要逐句時間碼、校對或 SRT 檔案時用字幕編輯器。

CHAPTER 10

字幕：上軌、下軌與從零新增

只編你要的那一軌，不再混入全部 AI 字幕。

要新增上軌字幕，先在字幕編輯器選「字幕上軌」，再按「＋ 一句」。

  1. 先把播放頭移到要出現的時間。左側「AI 字幕」區往下捲，找到「字幕編輯器」。
  2. 在最上方「編輯軌道」選「字幕上軌」。若上軌還沒有內容，會顯示 0 句；下軌 AI 字幕不會列在這裡。
  3. 按「＋ 一句」，直接打字。新增句子的預設文字已全選，輸入即可取代。
  4. 設定開始、結束時間。可輸入 00:00:03,500，也接受純秒數 3.5。
  5. 需要下一句時再按「＋ 一句」。它加在目前播放頭，不會自動接到上一句後面；請調整各句時間。
  6. 關閉編輯器並儲存專案。內容即時套用到目前專案，仍要按「儲存」才保留到專案檔。

操作作用在哪一軌？

操作範圍
＋ 一句目前「編輯軌道」選的上軌或下軌。
整批取代、轉台灣正體只改目前軌道。
清空本軌確認後只清掉目前軌道；另一軌保留。
編輯器內「存成 SRT」只輸出目前軌道；預設檔名加 _upper 或 _lower。
編輯器外的整份 SRT 匯出沿用全部字幕的匯出方式；分軌檔請在編輯器內儲存。

調位置、字體與軌道

在時間軸點選字幕方塊，右側可改文字、時間、字幕軌道、字體、大小、描邊及「畫面上方／下方」。樣式設定套用到這一軌的字幕，不是只有這一句。

字幕編輯器每句旁邊的軌道選單可搬動該句；把上軌句子改成下軌後，它會離開目前上軌列表，切到下軌即可找到。右側的 ▶ 可定位該句，⇊ 與同軌下一句合併，✕ 刪除該句。

「字幕上軌」不等於「字一定在畫面最上方」。軌道用來分組與決定疊放；實際字的位置要在右側調整。兩軌可設不同位置。

其他新增方式與重疊問題

在指定字幕軌的空白處雙擊，也能手動加一句。工具列的「＋ 字幕」則是匯入 SRT，不是開空白文字框。

同一軌在同一時間有多句重疊時，預覽和影片匯出只顯示其中優先的一句，新增的字可能被舊 AI 字幕擋住。調整時間避免同軌重疊，或分到上下軌並調整各自位置。右側會顯示重疊提示。

SRT 儲存優先使用已授權的專案資料夾；沒有可用資料夾時才嘗試另存視窗或下載。確認檔名與資料夾，再用文字檔或播放器檢查輸出的字幕。

CHAPTER 11

AI 自動產生字幕

設定辨識範圍，再逐句校對。

  1. 先加入影片，在左側展開「AI 字幕」。
  2. 選辨識「範圍」：整支影片或指定片段。再選模型與語言，可勾「轉成台灣正體」及「太長的句子自動斷句」。
  3. 可按「選資料夾」，存放模型、程式庫及 SRT。第一次使用需要網路下載相關檔案。
  4. 按「產生字幕」，等待完成。沒有 GPU 時會使用較慢的 CPU 路徑，介面會顯示狀態。
  5. 完成後開啟字幕編輯器，選正確字幕軌，逐句校對人名、數字、斷句和時間。

辨識整支影片時產生的字幕放在下軌；指定片段辨識時，字幕跟隨該影片片段的軌道。要再加另一組說明字幕，可在編輯器切到空白的上軌手動新增。

已有字幕時注意選項。重新辨識若選「取代（清掉舊的）」，目前版本會清掉既有的全部字幕，包含另一軌。若要保留手動字幕，先儲存專案，並留意追加／取代的選擇。這與字幕編輯器的「清空本軌」不同。

聲音在電腦內辨識處理；首次下載模型與程式庫仍需要連線。「離線準備」可先準備程式庫與引擎，模型則在首次辨識所選模型時下載。模型與檔案未準備完整前，不要把首次使用當成全離線流程。

CHAPTER 12

原聲、配樂與音量曲線

調整音樂長度、循環，以及說話時降低配樂。

影片原聲

選影片後，在右側「聲音」調音量；勾「原聲靜音」就關掉這段原聲。上下影片軌的聲音會一起混合，需要時分別靜音。

加入配樂

  1. 按「＋ 音軌」選音樂，也可把音檔拖到左側匯入區。
  2. 在右側設定「從第幾秒進來」「播多久」及「從音檔第幾秒取用」。
  3. 按「現在」使用目前播放頭時間；「到底」讓音軌延伸到影片結尾。
  4. 音樂不夠長時勾「循環填滿」，並用「接縫淡化」讓重播銜接較柔和。
  5. 調整音量、淡入、淡出後，實際播放聆聽。

說話時降低背景音樂

  1. 把播放頭移到音軌範圍內，按「在播放頭加一點」；也可雙擊音軌方塊空白處加點。
  2. 在說話前、說話開始、說話結束、說話後各放音量點。
  3. 把說話區間的點往下拉，兩側的點保留較高，形成降低再恢復的曲線。
  4. 右鍵點音量點可刪除；「清除曲線」會移除所有音量點。

音量曲線是乘在音軌音量上的倍率。例如音量 0.8、曲線倍率 0.5，該處就是 0.4。多條配樂會一起混音，「往前一條／往後一條」只整理列表順序。

沒有聲音時，先檢查播放時間是否在音軌範圍、靜音與音量曲線，再檢查 Edge 分頁、Windows 輸出裝置及耳機連接。

CHAPTER 13

輸出影片與覆蓋同名檔

編碼完成後，還要選位置儲存。

  1. 先儲存專案。保留可再修改的 .nvproj。
  2. 檢查「專案設定」。可選 16:9、9:16、1:1、4:3 比例，以及該比例支援的解析度；影格率有 24／25／30／60 fps，位元率範圍 2～40 Mbps。
  3. 檢查「畫面填滿」。「完整顯示（留黑邊）」保留全部素材；「裁切填滿」會填滿畫布並可能裁掉邊緣。
  4. 按右上角「匯出影片」。等待影片與聲音編碼，完成前可按「取消」。
  5. 按「選擇位置並儲存」。在 Windows 另存視窗選資料夾與檔名。
  6. 處理同名檔案。若詢問是否覆蓋，選「是」會寫入該檔案；選「否」後改檔名再存。
  7. 看到「影片已儲存」後，開檔確認。檢查字幕、轉場、畫面比例與音量，確認後再分享。
「影片編碼完成」還不等於檔案已儲存。v9.5 起，在支援另存視窗的 Edge，要再按儲存按鈕。取消另存或寫入失敗時，可以在同一個完成視窗重試，不需重新編碼。

通常輸出 MP4（H.264＋AAC）。若電腦不支援所需編碼器，程式可能改輸出 WebM，或提示無音軌；以完成視窗的格式與訊息為準。沒有原生另存支援時，會交由瀏覽器下載。

影片很大時，解析度、影格率與位元率都會影響處理時間和檔案大小。先用較短片段確認效果，再輸出完整成品，較容易找出有問題的素材。

CHAPTER 15

常見問題與排除

字幕看不到、GIF 不動、沒聲音及儲存疑問。

我要加上軌字幕，卻看到所有下軌 AI 字幕？

確認版本至少為 v9.7。打開字幕編輯器，最上方「編輯軌道」選「字幕上軌」，再按「＋ 一句」。上軌空白時應顯示 0 句。查看完整步驟 →

字幕已新增，為什麼預覽仍顯示原本那一句？

先檢查播放頭是否在新字幕起訖之內，再看是否與同軌舊字幕重疊。把時間分開，或搬到另一字幕軌並調整文字位置。新句子不會自動接在上一句後面。

調了關鍵幀終點，畫面卻沒有變？

播放頭如果停在動態開始之前，顯示的是起點。把播放頭移到動畫中間或終點範圍；也檢查該素材是否正被上軌遮住、透明度是否為 0，或圓形裁切直徑是否為 0。

GIF 為什麼不動？

請用「＋ 疊圖」匯入動畫 GIF，確認播放頭在疊圖時間範圍內。放進影片軌會作為靜態圖片處理；圖片本身也必須真的含有多個動畫畫格。

預覽音軌沒有聲音？

依序檢查：耳機／輸出裝置、Windows 與 Edge 分頁音量、素材是否靜音、播放頭是否在音軌範圍、音量曲線是否壓到 0，以及音檔不夠長時是否開啟循環。

匯出完成，找不到影片檔？

支援另存功能時，還要按「選擇位置並儲存」。請以「影片已儲存」為完成標誌。使用下載備援時，檢查瀏覽器的下載紀錄。

字幕樣式一改，為什麼很多句一起變？

字幕字體、大小、顏色與位置是按軌共用。上軌和下軌各有一組樣式；需要單獨做特殊大字時，可改用標題。

線上版沒有出現最新按鈕？

先儲存專案，再按 Ctrl＋Shift＋R 重新載入網站，確認左上角版本。開本機檔案時，確認開的是更新後的 NiVedit.html。

匯出或畫面仍然異常？

先存好專案，記下出問題的時間和素材名稱。到「專案設定」按「複製診斷資訊」，連同截圖提供給協助者，較容易定位原因。
