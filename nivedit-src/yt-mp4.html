NiVedit Basic · 獨立工具

YT → MP4

把 YouTube 影片的畫面與聲音存到電腦，再加入你的剪輯。

已啟動本機工具？

按下方按鈕開啟下載介面。貼上網址、選擇 720p／1080p／4K 畫質上限，即可下載及預覽。完成後為相容的 H.264／AAC MP4；原片畫質較低時不會放大。

開啟本機下載器 ↗下載 Windows 工具

若顯示「無法連線」，請先依下方步驟啟動工具，再按一次。

第一次使用

  1. 下載並解壓縮 Windows 工具。放在你可以寫入檔案的資料夾中，請勿直接在 ZIP 內執行。
  2. 雙擊「setup.cmd」完成初始化。需要 Windows 10／11 x64 與 Python 3.10 以上。初始化會下載 yt-dlp、Node 與 FFmpeg，需網路且可能花幾分鐘；不需要管理員權限。
  3. 雙擊「啟動下載器.vbs」。以 Edge 開啟；之後每次使用只需啟動這個檔案。
  4. 完成後加入 NiVedit Basic。在下載器按「另存 MP4」或「開啟下載資料夾」，回編輯器按「＋影片」。

已安裝 MP3 舊版工具的人，請先關閉工具，下載新版 ZIP 並覆蓋解壓到原工具資料夾，再啟動。MP3 與 MP4 共用這個新版工具。這是獨立功能，不會改動目前時間軸或自動替換配樂。

GitHub Pages 也能使用入口

GitHub Pages 提供操作入口與工具下載；實際下載及 MP4 轉檔由你的電腦處理。每一台電腦都需要先啟動本機工具，無法只靠網頁執行。

工具只接受單支 YouTube 影片。影片限制、登入要求或 YouTube 更新可能導致失敗，可查看詳細訊息；更新引擎請重新執行 setup.cmd。

請使用你有權下載的內容。工具不會讀取你的瀏覽器登入資料。關閉工具請用下載器內的「關閉本機工具」。
