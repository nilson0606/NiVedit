# NiVedit v12.3 原始碼

NiVedit 是瀏覽器端影音編輯器。主程式為 NiVedit.html，內建動畫素材位於旁邊的 animation-effects/；影片、音訊、字幕與專案都在使用者電腦處理，不上傳。

## 動畫效果素材庫（v12.3）

「＋ 動畫效果」提供兩種來源：內建 240 組素材，或「匯入自己的 GIF／圖片」。四包分別為表情與慶祝 40、常用效果 50、短影音效果 100、誇張效果 50；可搜尋、依素材包／分類篩選，先預覽再加入播放頭位置。選取後的分割按鈕為「動畫效果切割」。

本機雙擊 HTML 與 GitHub Pages 都可使用。建置時自動把 effect-assets/ 複製成輸出 HTML 旁的 animation-effects/，分發本機版時兩者一起帶走。第一次載入網站素材需要連線；GIF 加入專案後沿用既有 .nvproj 封裝，不依賴網站重開。

正常建置只需 Python 3：python build.py [輸出HTML路徑]。來源包已含素材，不需原始素材包或 Pillow。只有重新產生素材時，才執行 tools/build_effect_assets.py [原始assets資料夾]，並安裝 Pillow。請勿把含本機路徑與提示詞的原始 manifest 直接發布。

內部 overlay／over 資料欄位維持相容。預覽採縮圖與單一 GIF 圖片；加入時間軸才解碼動畫。保留影片剪輯、關鍵幀、匯出、PNG／GIF 本機匯入等既有功能。

## v9.6

## 建置

在 `D:\NiVedit` 執行：

```powershell
python nivedit-src/build.py
```

輸出為根目錄的 `NiVedit.html`。第三方函式庫已放在 `vendor/`，不需下載 npm 套件。

`build.py` 會先由 `src/dict_en.tsv` 產生 `src/06_dict.js`，再依固定順序合併 `src/`。新增原始碼檔案時也要更新 `build.py` 的載入清單。
